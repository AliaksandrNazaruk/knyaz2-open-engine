# Формулы боя: «Кровь Титанов» против Slavik (открытый «Князь 1»)

Slavik — открытая реализация «Князя 1» на C++ (github.com/Marisa-Chan/
Slavik, клон в `project/community/slavik`, глубина 1). Автор реверсил
первый движок и СОХРАНИЛ адреса оригинала в именах функций (FUN_0041c480
и т.п.), поэтому его код — независимый читаемый источник по родословной
наших формул: К2 вырос из К1. Сверка 23.08.2026, наша сторона — 
`docs/COMBAT_SPEC.md` (снята дизассемблером konung2.exe).

## Доказано числами, не сходством

* **Таблица парирования по направлениям**: их литерал `Can[8][8]`
  (game_play.cpp, FUN_0041c480) совпал с нашей таблицей `0x459F94`
  **все 64 байта один в один** (проверяет
  tests/test_combat_formula_heritage.py прямо по exe).
* **Константы формул** из konung2.exe (double по адресам 0x450138…88):
  0.1, 0.7, 0.3, 16.0, 0.001, 0.5, 0.7, 0.3, 16.0, 0.001, **0.00025**
  — каждый литерал Slavik стоит в нашем exe тем же числом; 0.00025
  (износ оружия) до сверки в спеке значился безымянным `_DAT_00450188`.

## Унаследовано К2 из К1 без изменений

| что | К1 (Slavik) | К2 (наша спека) |
|---|---|---|
| потолок здоровья | 1600 | 1600 (0x640) |
| формула урона | `(1 + (max(0, сила·0.7 − броня) + сила·0.3) / делитель) · 16` | та же, команда в команду |
| порог слабого удара | `hit < 48` → код −1 | `урон < 0x30` → −1 |
| коды исхода | 1 смерть / 0 удар / −1 слабый / −2 мимо | те же |
| парирование ближнего | таблица 8×8 + `rand%101 ≤ Ловкость·0.5` | то же (порог с ROUND) |
| износ брони жертвы | три гнезда, `min(1, сила/броня) · Dmg · 0.001` | гнёзда 2…4, тот же множитель |
| износ оружия | заряд/отрава −1, `прочность −= сила · 0.00025` | то же, @0x450188 |
| отрава | глобал (их `00a3e828`) | глобал `0x849704` |
| гейт резолвера | `_bGodMode && chr == main` | `[0x849620] && жертва == [0x84951C]` |
| спец-урон против класса | SpecialDamages: ClassID → Dmg | таблица 0x4624F8 «вид оружия против породы» |

## Эволюционировало в К2

* **Делитель урона**: у К1 живая Выносливость; у К2 — отдельное поле
  «стойкость» `+0xD1`, пересчитываемое 0x41C494 (и не бывающее нулём).
* **Точность**: у К1 считается из Ловкости (FUN_0041b4cc, три ветки
  оружия); у К2 — из НАВЫКА оружия с прибавками (0x41ADD8 / 0x41A9C8).
* **Парирование стрел**: у К1 порог как у ближнего, Ловкость·0.5; у К2
  ослаблено до Ловкость·0.1 и сравнивается без округления (@0x450138).
* **Смертельный удар** (навык `+0xD4`, минуя урон и износ) — в К1 его
  нет вовсе, чистое добавление К2.

## Что это закрыло в спеке

Вопрос 2 раздела «Осталось» COMBAT_SPEC.md: гейт `0x849620` — это
режим бога (у Slavik буквально `_bGodMode`); в К1 он взводится читом.
Пометка перенесена в спеку.

## Грабли

Slavik — «Князь 1», не Кровь Титанов: совпадение формул К1 и К2 — это
родословная, а не тождество движков. Каждое утверждение о К2 выше стоит
на нашем дизассемблере; Slavik подтверждает и называет по-человечески,
но арбитром для К2 не является.
